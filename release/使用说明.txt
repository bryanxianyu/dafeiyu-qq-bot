🐟 养大肥鱼 v__FISH_VERSION__ —— 让 DeepSeek 住进你的 QQ

【需要准备】
- Windows 10/11 64 位
- DeepSeek API Key：https://platform.deepseek.com/api_keys （要充一点余额）
- 一个给机器人用的 QQ 小号（别用大号）
不需要装 Node.js / Python / QQ，全都内置或自动处理。

【使用】
1. 双击桌面上的「大肥鱼」，浏览器会自动打开控制台；右下角托盘里有一条小鱼
2. 在「基础设置」填 API Key 和你的 QQ 号，保存
   - 第一次会自动安装 QQ 组件（从腾讯官方下载，约 200MB）
   - 「运行状态」页会出现二维码，用机器人小号的手机 QQ 扫码
3. 用你的 QQ 私聊机器人；群里 @ 它或叫它名字，开了「自然插话」它也会自己接话
   - /状态：看模型和会话
   - /重置：换一缸水（清空当前对话；要紧的事它会先记进长期记忆）

关掉浏览器不影响运行。要彻底退出：右键托盘里的小鱼 →「退出大肥鱼」。

【人格卡 & 记忆】
- 人格卡：身份、性格、说话风格、规则、示例对话，可以按群/私聊用不同的卡。
- 绝对人格记忆：永不遗忘的核心事实。和人格卡一起常驻在它的系统提示里，
  每一句话都在场，不会被长对话挤掉——所以聊再久也不会“变了个人”。
- 长期记忆：它会自动把聊天里值得记的事整理下来，按艾宾浩斯遗忘曲线慢慢淡忘；
  被想起一次就加固一次，越是快忘时想起，记得越牢。淡到看不清就进「遗忘区」，可以恢复。
- 它觉得可能要永久记住的核心事实，会出现在「记忆 → 待确认」里，由你决定。

【表情包 & QQ 空间】
- 表情包：它会按情绪挑表情包发。群里别人发的表情包会被自动收集、看图打标签，
  在控制台「表情包」页审核通过后才会用；也可以自己上传。每看一张图约 550 token。
- QQ 空间（默认关闭）：在「空间」页打开后，每天到点写一条“鱼的日记”私聊给你，
  你回「发」才发出去；你也可以在私聊里让它发。群里谁说都没用。
  走的是非官方接口，可能失效；机器人号频繁发帖有风控风险。

【安全说明】
- 只有白名单里的 QQ / 群能和它说话，陌生人一律不理。
- 群聊和其他人私聊默认「只聊天」：程序层面禁止它执行命令、读写文件、联网（可在「安全」页改成只能联网）。
  只有主人自己的私聊能用完整能力（沙箱内执行命令，高危操作自动拒绝）。
- 伪造“主人”身份、让它改人设、套系统提示、往记忆里塞指令，都有专门防护；详见控制台「安全」页。
- 控制台只允许本机访问。data\config.json 里存着你的 API Key，别把整个文件夹发给别人。

【卸载】
「设置 → 应用 → 大肥鱼 → 卸载」，或开始菜单里的「卸载大肥鱼」。可以选择保留聊天记录和记忆。

【常见问题】
- 二维码一直不出来：看控制台「日志 → NapCat」。
- 大肥鱼显示「等待 QQ 连接」：QQ 还没登录好，扫码后会自动连上。
- 回复「呛水了：…401…」：API Key 不对或没余额。
