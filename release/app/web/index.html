    记忆设置
    
      
      
    
        
        
        
        
      
    
      
    它是怎么遗忘的？
        
    按艾宾浩斯遗忘曲线：清晰度 R = e−t/S，t 是距上次想起的时间，S 是牢固度。新记忆的牢固度由重要度决定（琐事半天、极重要 21 天）；每被想起一次，牢固度 ×(1.2 + 2×(1−R))——快忘时想起，加固最多。点表格里的一条可以看它的曲线。

    安全
    群里任何人都能给它发消息，有人会故意发“指令”让它改人设、读你电脑上的文件。这里决定它在哪能动手——由程序强制执行，不靠它自觉。

    一直开着的防护
    
      
      
        
    • 别人伪造的“系统提示”“[主人]”标注不会被当真，主人身份只认 QQ 号。
      • 
        
    • 不接受别人改设定，不透露设定原文和主人隐私。
      • 
        
    • 不记“以后你要……”“你的主人是……”这类指令；别人只能留下关于他自己的记忆。
      • 
        
    • 群名片里的括号、分隔符会被清掉，防止冒充别人。
      • 
        
    • 表情包只收 QQ 图片和网上安全搜索的结果，下载前检查地址，不碰本机和局域网。

    扩展 开发者
    给会写代码的人用：把自己的人格系统、记忆系统做成扩展接进来。普通使用不需要动这里。启用/停用后重启大肥鱼生效。
    
    
    
    
    
      
    
      
    
    
    
    
      怎么写一个扩展
      
    
        
    在 data\extensions\ 下建一个文件夹（），放：
    

    manifest.json  { "id": "my-memory", "name": "我的记忆", "type": "memory",
                 "entry": "index.mjs", "panel": "panel.html", "priority": 0, "enabled": true }
config.json    扩展自己的配置（设置页通过 FishExt.getConfig / setConfig 读写）
index.mjs      导出任意几个钩子：

export async function init({ id, dir, dataDir, config, logger }) {}
export async function persona(chat) { return "人格卡文字"; }            // 取优先级最高的非空结果
export async function recall(chat, sender, text) { return "相关记忆"; } // 所有扩展结果拼接后注入
export async function remember(chat, sender, text, reply) {}            // 回复后调用
export async function dispose() {}

chat   = { key: "group:123" | "private:456", type, id }
sender = { userId, nickname, isOwner }

panel.html     设置页，引入 <script src="/sdk.js"> 后可用 FishExt.getConfig() / FishExt.setConfig(obj)
    
        
    两个模板「人格卡（模板）」「记忆系统（模板）」就是完整示例，复制一份改名即可开始。
